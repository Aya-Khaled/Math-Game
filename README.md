# 🧮 Math Challenge Game | C++

A console-based math game developed in C++ as part of my programming learning journey through the **AbouHadhood Platform**, following Dr. Mohamed Abou Hadhoud's training track.

The game generates random arithmetic questions and challenges players to solve them accurately. It provides an opportunity to practice fundamental programming concepts while working with mathematical operations.

## ✨ Features

* 🎲 Generate random math questions.
* ➕ Practice addition.
* ➖ Practice subtraction.
* ✖️ Practice multiplication.
* ➗ Practice division.
* 🧠 Improve arithmetic skills and problem-solving.
* 💻 Interact with the game through a command-line interface.

## 🛠️ Built With

* **C++**
* `iostream` — for input and output.
* `cstdlib` — for random number generation.
* `ctime` — for initializing the random number generator.

## 🧠 Concepts Practiced

Through this project, I practiced:

* Conditional statements and decision-making.
* Loops and repetition.
* Functions and code organization.
* Random number generation.
* User input and output.
* Arithmetic operations and basic problem-solving.

## 🚀 Getting Started

### Prerequisites

You need a C++ compiler, such as GCC or MinGW, installed on your computer.

### Run the Project

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Compile the C++ source file using your compiler.
4. Run the generated executable to start playing.
